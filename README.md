# SJSU Data Mining - Assignment 1 (Part 2)

This repository contains 5 end-to-end Data Science & Machine Learning applications following the CRISP-DM framework. 

> Project Structure Note:  
> Each project folder contains:
> - **`app.py`**: The full application source code powering the Streamlit web dashboard.
> - **`prompt.md`**: The exact prompts provided to ChatGPT to generate and document the project.
> - **Screenshots**: Visual proof of running dashboards, CRISP-DM workflows, and live model predictions.
